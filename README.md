# EventEase

Application mobile de gestion d'événements pour l'association EventEase : consultation, création, modification et suppression d'événements, et suivi de la participation des membres.

Projet de formation Concepteur Développeur d'Applications.

## Stack

- Expo SDK 57, React Native, TypeScript
- Expo Router (basé sur React Navigation)
- AsyncStorage pour la persistance locale

## Prérequis

- Node.js (version LTS)
- L'application Expo Go sur un téléphone Android ou iOS

## Installation

```bash
git clone https://github.com/antoine62232/eventease.git
cd eventease
npm install
```

## Lancement

```bash
npx expo start
```

Scanner le QR code affiché avec Expo Go. Le PC et le téléphone doivent être sur le même réseau Wi-Fi.
